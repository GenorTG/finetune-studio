## Cross-cutting gaps (cut across many pages)

| Gap | Affected pages | Notes |
|---|---|---|
| **No per-project activity log** | dashboard, project dashboard | `/api/activity` only shows live tasks, not history. Need a `project_activity` table that records every action (file upload, prep start/stop, training start/stop, benchmark, RAG build, export, settings change) with timestamp + actor + payload. Surfaces on `/projects/{pid}` and on `/`. |
| **No versioning UI for files** | data-prep | API has `/{fid}/versions` but no UI. Show version pill (`v1`, `v2`, ...) + a "history" modal with each version's mtime, size, hash, parser output. |
| **No conversions UI** | data-prep | API has `/{fid}/conversions`. Show the parser chain (raw → markdown → chunks) with each stage's stats. |
| **No rollback** | training, files | Need a `/api/projects/{pid}/files/{fid}/rollback?v=N` endpoint + button in versions modal. Same for training runs (re-promote a previous production_run). |
| **No export-list-detail** | models, export | Expand-row showing the actual files in the export dir with sizes. |
| **No "open in inference"** | models, training | Button on each row that POSTs `/api/models/load` then redirects to `/inference`. |
| **No project-level search** | dashboard | Cmd+K palette searches globally but not within a project. Useful for "find any run/dataset/file in this project". |
| **Stats stale on dashboard** | dashboard, /inference | RAM/VRAM polled but not refreshed on user-visible cadence. Need a `setInterval` that hits `/api/system/gpu` every 5s. |
| **Wall-of-text sub-text** | data, data-prep, training, chat | Sub-text under page heading is 2-3 lines of dense explanation. Compress to one line + link to `/docs/concepts/{topic}` for the long version. |
| **Contrast / size** | most pages | `--text-dim` (`#666`-ish) on `--bg` (`#000`-ish) is borderline. Bump body font from 13px → 14px; bump muted from `11px` → `12px`; bump `--text-dim` contrast ratio. |
