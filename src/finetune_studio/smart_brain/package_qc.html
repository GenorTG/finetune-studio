Quality checks

Test the shipped question set against this installed package. Retrieval checks compare exact source IDs and need no LLM. Answer runs save transcripts with no verdict; Judge answers asks the operator's model separately. A retrieval hit is not proof of a correct answer.

Load checks once to create the private owner-token file if needed. Keys are used only on this page and never saved.
