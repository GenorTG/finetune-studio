Connect your Smart Brain

Your package retrieves evidence. Your AI client and its model write the answer. No LLM is included.

1 · Prepare the client's machine

Extract this package on the Linux machine running your MCP client, then run bash install.sh. Keep the encryption passphrase in a private file (chmod 600 /path/to/passphrase.txt). For a remote HTTP connection, start bash run-http.sh --keyfile /path/to/passphrase.txt on the package host.

Paths below refer to the client's machine, not necessarily this web server. Nothing entered on this page is saved. A server access token is different from the encryption passphrase.

2 · Choose your client

Blank matches the port of a direct localhost HTTP address. For HTTPS, public addresses or proxy paths, enter the package's internal listener port (usually 8899), not the proxy's public port. If localhost is itself a proxy, enter the internal port explicitly. Only the startup command changes; client URLs and checks still use the HTTP address above.

For remote clients use HTTPS and bearer authentication. Loopback inside a container means that container.

Optional · Install the MCPB bridge


Download Linux MCPB bridge


For MCPB-capable hosts: import this unsigned bundle, then select the already installed package folder and private keyfile.
The small bridge connects to those local files; it contains no knowledge, passphrase or model and does not install Python dependencies.


Claude Desktop is not certified here. Its official MCPB hosts are macOS and Windows; this product currently supports Linux only.
The bundle declares Linux compatibility only. Do not treat it as a working one-click Claude Desktop installer.


Client verification status


Local stdio and HTTP MCP transports are tested. Recipes are not vendor certification.
Claude Code 2.1.325 passed model-driven synthetic text retrieval over plaintext stdio, encrypted stdio and encrypted MCPB bridge on one Linux host; HTTP, images and clean-machine installation are not certified.
Gemini CLI configuration was accepted, but its connection check requires client authentication.


Cursor, VS Code Copilot, Windsurf, LM Studio and Open WebUI have not been certified through their actual user interfaces.
ChatGPT Actions setup and its retrieval-only relay are available above; OAuth, automatic tunnels and a direct Ollama MCP host are not shipped. Choose an MCP host such as Open WebUI for Ollama.


For setup details and limitations, use each client's documentation link above.
GET /v1/models advertises smart-brain; POST /v1/retrieve returns passages,
scores and optional pictures; POST /v1/chat/completions provides text chat through the operator's LLM.
JSON replies attach knowledge.sources; buffered SSE attaches knowledge to the final chunk.
This is not token-by-token upstream streaming. Tools, attachments, usage accounting and arbitrary generation parameters
are not supported and unsupported requests fail explicitly. Client requests cannot widen package scope or change its upstream.
