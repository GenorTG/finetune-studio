Usage & missing knowledge

Local owner diagnostics for this installed package. Counts only by default. No telemetry is sent to Studio or any vendor. Open this page on the package host; history and settings are not available to remote clients.

The first Load usage creates this private file on the package host. Read its contents locally and enter them here. This separate key protects history even when the package server token is shared with AI clients. Neither key is saved by this page.

Privacy & retention

Diagnostics are a private local SQLite sidecar, not encrypted by the corpus passphrase. Opting into query text stores up to 2,000 characters per question in plaintext. Never records answers, passages, provider keys, attached images or exception messages. Retains at most 10,000 operations, including failures.

Switching to counts only erases retained question text immediately. Retention is applied on every write and read; when the package is stopped, no expiry worker runs. Shortening retention deletes older events. Totals cover only retained events.

Export & document suggestions

Not-found, low-confidence and thumbs-down events are candidates for review, not proof that knowledge is missing. Export the missing-knowledge report, then import it on Studio’s Package page. Counts-only reports cannot name the missing question; collect an example from the user before choosing a document. Nothing is added to package scope automatically.
