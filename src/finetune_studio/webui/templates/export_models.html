Build the package

One archive with your documents' index, who it speaks for and how to answer, a small Python server (HTTP + MCP), installer, run and update scripts. Encrypted by default (AES-256-GCM); the passphrase is shown once and never stored.
Build the Smart Brain first: the package is made from its index. Build the Smart Brain
Who it is for
Documents in the package

A package for a public chatbot can carry only part of the index (for example the public/ folder); the rest is not inside at all, so it cannot be found or read through it.

Folders
Tags
Single documents
Files and sources

Anyone with access to the package server can download them. Leave this off for a public bot.

Answers

Off: the package returns passages with sources and your own model or agent writes the answer (the usual MCP setup). On: it also answers, with the connection below.

No API key is stored in the package: where the server runs, set RAG_LLM_API_KEY, or type a key in the package's chat page (it is sent with each question and never saved).

Version
Use an exported package file as the base

Only its id, version and document list are read (to compare against); nothing else is kept.

Advanced: server and search options
Search layers in the package

Each layer is separate. The package ships only the files the layers you keep need, and its server can switch a shipped layer off at run time (--no-semantic, --no-keyword, --no-reranker).

⇄ Rank fusion (RRF) on: merges the two rankings
Passphrase (shown once — copy it now, it is not stored anywhere):

Runs anywhere with Python 3.10+. Word search works out of the box; meaning search needs the models inside or an embeddings endpoint where it runs (see the line above the button). Settings baked in here are written to rag.config.json inside the package and can be overridden by env vars and flags.

Package versions
Every exported package keeps its id; a new version of it lists the documents added, changed and removed since the last one. A running copy updates in place with bash update.sh NEW.tar.gz.
