🧠 Smart Brain

Step 2 · Answer from your files, no training. The Smart Brain reads the files you prepared in Files & Knowledge, finds the passages that answer a question and quotes them; then chat with it or test it (step 3).
Methods: semantic search (multilingual embeddings) + keyword search (BM25), combined by rank fusion, then reranking (cross-encoder); an answer gate declines when nothing found covers the question. Often called RAG (retrieval-augmented generation).
More about the Smart Brain

It reads exactly the text that training uses: each file is parsed once in Files & Knowledge, including pictures read by the Vision reader and your hand edits. New or edited files only need a rebuild (minutes, not hours) and model weights never change. Export it as an encrypted bundle or a standalone server that runs without this app.

How the Smart Brain fits in
Files are prepared once; the Smart Brain and training both read that one parse.
  1. Upload files in Files & Knowledge; each one is parsed on arrival (pictures are read by the Vision reader during mining)
  2. Check or edit the parsed text there if a file read badly
  3. Build the index below (section 2); the status shows files that changed since the last build
  4. Test a search and chat below, or score it on the test page

Stored on disk: the passages, their vectors, the keyword index and the search settings. Shared embedder and reranker weights live under ~/.finetune-studio/shared_models/ (not inside your fine-tuned model).
