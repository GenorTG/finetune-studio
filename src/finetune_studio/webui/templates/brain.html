🧠 Smart Brain

Ask questions about your files and get answers with their sources. No training needed.
How it works
  1. Add files here or in Files & Knowledge. Each file is read once; you can check or correct the text there.
  2. Build the index. New or edited files only need an update, and the status below says when one is due.
  3. Ask, then score it on your own questions.

The index is external memory: model weights never change. Search combines multilingual semantic embeddings with BM25 keyword matches using rank fusion, then reranks passages with a cross-encoder. An answer gate declines when no passage supports the question; this is often called retrieval-augmented generation (RAG).

Stored on disk: the passages, their vectors, the keyword index and the search settings. Shared embedder and reranker weights live under ~/.finetune-studio/shared_models/. Agent chat can recommend settings and start a build for you.

Import an index or open a package
Load an encrypted .ftsrag bundle someone exported from their Smart Brain (or a legacy .tar/.zip): it brings the passages, vectors and keyword index. Or open an exported package (.tar.gz / .zip with its passphrase) to edit it: its index becomes this project's, its original files (when it ships them) come back into Files in their folders, and the next export can be a new version of it.
Shared search models
The embedder and reranker model files (the helpers that turn text into searchable numbers) live in ~/.finetune-studio/shared_models/ — one copy shared by every index here. They are separate from your fine-tuned chat models in the Model workspace.
