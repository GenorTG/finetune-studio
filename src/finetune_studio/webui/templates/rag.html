RAG — Retrieval-Augmented Generation

External document memory for this project: retrieve facts from an indexed corpus at query time. This does not change model weights — that is the Model workspace (Training). Upload and parse happen on Data Prep; this page only embeds and queries.
Data Prep / Upload Sources → Project file library
{# First-time workflow — Upload is elsewhere; RAG starts at Embed #}
How RAG fits in
Source files (uploads + parsed text) live in Data Prep. Indexed corpus documents/chunks live here after Embed.
  1. Upload files on Data Prep
  2. Parse into text sources (auto for .txt/.md, or promote)
  3. Prepare / QA optional training pairs (Model path)
  4. Embed parsed sources into this corpus (section 2)
  5. Test retrieval and chat below

Persistent on disk: corpus chunks, vectors, BM25 index, and retrieval settings. Shared embedder/reranker weights live under ~/.finetune-studio/shared_models/ (not inside your fine-tuned model).
