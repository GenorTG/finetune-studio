📚 Search my files — RAG index

The no-training flow. Your documents are indexed here, and at question time the model looks up the relevant passages instead of remembering them — so answers can quote the source, and new files just need a rebuild. Minutes, not hours, and model weights never change (that is training).
Steps: upload on files → build below → search → chat grounded in the documents.

{# Test #}
5. Search test
Search the corpus and see which passages come back — no AI answer is generated. Use it to check whether your build and settings retrieve the right text before you chat or train.
{# Chat #}
6. Ask the model (grounded)
Chat that looks up your documents first and answers using them as context (needs a chat model loaded — see the pill in the top bar). The grounding comes from this index, not from fine-tuned weights.
{# Bundle #}
7. Download / export the corpus
One archive with everything: documents, chunks, vectors, keyword index, and your settings. Optionally include the search models so it works on a machine with no internet. Export copies files — the live corpus is never changed.

"Include models" adds the search-model files to the download only (roughly 2 GB extra). The live corpus is never changed. Uncheck for a small text-only archive (~30 KB) that always leaves out model files.

The standalone package runs anywhere with Python 3.10+. Keyword search works out of the box; for meaning-based search point it at any embeddings endpoint (LM Studio, Ollama, OpenAI) — the README inside explains both. Check "Include models" first to bundle the embedding model inside the package — then it does full semantic search completely offline, no provider needed at all (roughly 2.3 GB download).

{# Shared models #}
8. Shared search models
The embedder and reranker model files (the helpers that turn text into searchable numbers) live in ~/.finetune-studio/shared_models/ — one copy shared by every corpus here. They are separate from your fine-tuned chat models in the Model workspace.
