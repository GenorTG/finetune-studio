About

      
Finetune Studio · EARLY BETA · v{{ app_version }}

      

      

        

          EARLY BETA: a hobby project for local models: build a Smart Brain from your files,
          fine-tune on your own hardware, test the result, chat. It runs on this machine; an API helper is optional
          and only used if you connect one.
        

        

          See README.md for the full
          rationale, docs/INSTALL.md for installation, and
          docs/ATTRIBUTIONS.md for package licenses.

    Test judge
    
        
    After a test run saves the model's raw answers, a judge decides whether each one is correct. The judge is any model you have connected (see the helper model below and the provider list); you can always override it by hand on the Testing page.
    
      
    
      
    
        
        
        
    A local GGUF judge loads onto the GPU after the run (the tested model is unloaded first); an API judge needs no GPU. Leave on the helper seat unless you want a stronger judge.
    
      
    
      
    
        
        
    Off: a run ends at the raw transcripts and you start the judge (or review by hand) from the Testing page.
    
      
    
      
    
        
        Idle.

    Vision reader
    
        
    Reads pictures inside your documents while mining: scanned pages, charts and tables pasted as images. Without it, those pictures are mined from OCR text, which keeps the numbers but often loses which label each number belongs to.
    
      
    
      
    
        
        
        
      
    
      
    
        
        
        
        
    It loads into the one inference worker while a batch with pictures is mined and is unloaded after. With a local helper, pick the helper's own GGUF here (if it has an mmproj) or use an API vision model.
    
      
    
      
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    With an API vision model, the pictures in the documents you mine (scans, charts, page images) are sent to that provider.
