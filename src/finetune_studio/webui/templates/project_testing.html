Testing

Step 4 · Train a model. Did it actually learn your material? A test is two separate steps: 1 · Run asks the model your questions and saves exactly what it answered next to the correct answer; 2 · Judge lets an AI judge (any model you have connected) or you read each saved answer and decide pass / partial / fail. Nothing is scored by string matching.
Quizzes come from your own dataset or an imported file; LLM-assisted quiz generation uses {{ helper_label }} only — never a silent fallback to another loaded model. Public leaderboards (MMLU/GSM8K) run on benchmarks with their official scoring.
